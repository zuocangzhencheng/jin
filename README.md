# A股交易工具

一个面向 A 股散户的本地静态交易 App。它不是荐股工具，而是帮助使用者执行交易纪律：盘中少做冲动交易，盘后把个股图形、均线、买卖标记和笔记沉淀下来。

当前版本：`v1.8.1 数据与样本加固`

知识手册：[交易知识体系手册](docs/trading-knowledge-system.md)

## 项目定位

这个 App 解决三个核心问题：

1. 为什么盯？
2. 什么条件才买？
3. 错了在哪里卖？

它把自选股、市场环境、主线强度、资金异动、集合竞价、K 线状态、纪律缺口、资源轮动方向、复盘K线和复盘日志放在同一个 App 里，帮助使用者少做冲动交易，多做条件确认。

`v1.6.0` 开始，界面进一步收敛为“单 App 多页签”：默认首页只看今日行动清单、持仓风险和市场环境；自选、主线、雷达、复盘K线、复盘日志和设置分开进入，避免所有模块挤在一个长页面里。

`v1.6.1` 继续做减法：总览页前置市场环境和数据状态，主线强度只显示 Top3；自选卡片默认折叠；新增盘中/盘后/完整模式；K线增加腾讯备用源，避免单一行情源失败时整页无K线。

`v1.6.2` 把选股和复盘连成纪律闭环：自选新增核心/临时/淘汰分层，卡片新增交易计划状态和今日禁止操作；复盘K线的真实买入记录会同步主自选成本和股数，并新增执行评分。

`v1.6.3` 补齐卖出复盘：复盘K线新增卖出标记、卖出原因和计划内外；执行评分会检查卖出纪律；新增 Excel 式复盘表，可记录交易流水、错误类型和明日计划，并导出 CSV 用 Excel 打开。

`v1.6.4` 新增利弗莫尔市场钥匙纪律：自选卡片会标注上升趋势栏、自然回撤栏、自然反弹栏和下降趋势栏；今日行动和禁令区会提示三点突破、亏损不加仓、趋势破坏和自然回撤等待，帮助在科技分歧时先守本金。

`v1.6.5` 新增估值温度：自选和核心观察会拉取 PE/PB/总市值/ROE，并按成长股、平台股、周期股分别提示估值低温、中性、偏热、极热或低PE核周期。估值只作参考，不会替代K线、资金、买点和风控。

`v1.6.6` 新增强势三闸门：大盘站上10日线、板块相对大盘强、个股相对大盘强，三项同时打开才允许进入六灯买点筛选。三闸门不开，六灯再亮也不买；三闸门开了，再用六灯筛买点。

`v1.6.7` 做减法：移除废弃的黄金/贵金属报价模块，总览页只保留市场环境、今日行动、持仓风险和数据状态；买点展示改成纪律检查语气，信号通过也只提示按计划小仓/分批执行。

`v1.6.8` 修复雷达可靠性：资金异动雷达新增 `fetch` 备用源，东方财富 JSONP 脚本加载失败时会自动重试；雷达空状态会区分接口失败、原始数据为空、主板/市值过滤、异动阈值未达标，避免把所有情况都显示成候选 0。

`v1.6.9` 新增雷达保留：资金异动雷达只要扫到过有效信号，就会保存最后一次有效结果；休市、接口空或本轮没有新信号时，页面会继续展示最后有效雷达并明确标注“保留”，用于盘后复盘方向，不把旧异动当买点。

`复盘K线台 v0.4.1` 新增复盘自选删除：可以把股票从复盘K线列表移除，并阻止下次被主自选自动同步回来；买卖标记、笔记和Excel复盘记录会保留，方便误删后重新加入恢复查看。

`v1.8.0` 统一并加固交易规则：三闸门检查已完成上证日K收盘与MA10、主题相对大盘强度、个股相对主题及大盘强度；六灯不再把趋势和形态重复计票，并补上独立资金灯。形态确认与仓位许可分开，只有计划买价、结构止损、已确认的单笔风险上限和可计算整手仓位齐备后才显示允许小仓。

成交量在日K未完成时显示为盘中待确认，不把部分日成交量冒充完整日量比。持仓新增批次和可卖数量按T+1管理；旧仓没有批次资料时需要手动核对可卖股数。复盘K线当日卖出标记会检查主自选的可卖数量。确认买点会留存信号时点快照，后续复核标签由用户手动记录，按形态与市场阶段汇总，不构成自动回测或收益保证。

`v1.8.1` 补齐数据缺失的等待状态：指数报价不足时不按0%大盘参与相对强弱，盘中没有当日K线时旧日量不通过量能灯。确认买点样本在自选筛选前留存，并附相对强弱、MA10、量能数值。复盘流水拒绝未来日期；T+1校验失败的卖出不会因编辑自选而被静默标记为已处理。

## 快速开始

不需要安装依赖。

入口页：

```text
index.html
```

选股监控台：

```text
outputs/stock-watch-app/index.html
```

复盘K线已内嵌在选股监控台的“复盘K线”页签里，不需要从第二个入口进入。

如果浏览器限制本地行情请求，可以用任意静态服务器打开。例如：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```

## 本地校验

已内置 `jsdom` DOM 校验环境，用来检查页面脚本能否在浏览器 DOM 下正常启动并渲染关键模块。

网页运行本身仍是静态文件，不需要安装依赖；运行 DOM/规则测试时需要安装 `package.json` 中的开发依赖。

Windows 下直接运行：

```cmd
verify-dom.cmd
verify-review.cmd
verify-trade-rules.cmd
```

或在 Node/npm 可用时运行：

```bash
npm run verify:dom
npm run verify:review
npm run verify:trade-rules
```

## 复盘K线

复盘K线作为选股监控 App 的内置页签存在，页面会同步主监控台自选，避免在两个地方重复加股票。

- 输入股票代码或常见股票名称即可加入复盘列表。
- 加入时自动拉取当前价、涨跌幅和日K数据。
- K线图显示蜡烛图、成交量、MA5、MA10、MA20。
- K线优先使用东方财富日K，失败后自动尝试腾讯备用源，并在图上提示数据源状态。
- 买入后可以输入买入日期、买入价和股数，K线上会用蓝色 B 标出真实买入位置。
- 卖出后可以输入卖出日期、卖出价、股数、卖出原因和是否计划内，K线上会用红色 S 标出真实卖出位置。
- 自动计算平均成本、剩余持仓、已卖股数、已实现盈亏、浮动盈亏、总盈亏金额和盈亏比例。
- 买卖记录会同步到主监控台自选持仓，自动更新剩余成本、股数和持仓状态。
- 新增执行评分，检查买入记录、追高位置、卖出纪律、仓位纪律、复盘计划和成本反馈。
- 新增 Excel 式复盘表：可写入日期、股票、动作、价格、股数、板块、盈亏、计划内外、错误类型和明日计划，并导出 CSV。
- 支持 60日、120日、240日切换。
- 每只股票单独保存复盘笔记，可以用强承接、缩量回踩、放量分歧、等确认等标签辅助记录。
- 买卖标记是你的真实交易记录，用来复盘是否按计划买入、按计划卖出，不会自动生成荐股买卖点。

## 当前功能

### 1. 自选股监控

- 支持持仓和观察分组。
- 观察池支持核心观察、临时观察和已淘汰分层，方便自选变多后只盯重点。
- 支持成本价、持仓股数、目标价、止损价。
- 支持输入股票代码或常见股票名称自动识别。
- 支持自选列表本地保存。
- 支持自动刷新，默认 60 秒一次。
- 自选列表默认智能排序：强信号和高分观察在前，持仓紧随其后，低分观察沉底。
- 新增“重点”筛选，只看强信号、高分观察和持仓，避免自选过多时一直下拉。
- 新增核心、临时、淘汰筛选；已淘汰会沉底，只保留复盘，不参与盘中追买。
- 每只自选股票显示主定位、细分定位、产业链位置、关键逻辑和易误区。
- 常用核心票使用精确定位表，未覆盖股票只做主线和备注推断，避免误分类。

### 2. 模块折叠

- 每个大模块都支持单独收起和展开。
- 顶部支持一键全部折叠、全部展开。
- 折叠状态会保存到本地，刷新页面后继续沿用上次布局。

### 3. 交易三问

每只自选股卡片会显示：

- 为什么盯：主线强度、评分、趋势、量能、资金雷达等原因。
- 什么条件买：严格买点是否满足，以及当前还差什么条件。
- 错了在哪里卖：止损、跌破关键均线、放量分歧、目标价分批等风控条件。

核心原则：

- 新闻不是买点。
- 异动不是买点。
- 买点必须同时看市场环境、主线、K 线、量能、资金和风控。
- 环境不是只看大盘红绿；大盘弱但个股红盘并明显跑赢指数，会标记为逆势强或逆势抗跌。

### 4. 交易计划检查

新增或编辑自选股时，可以提前写好：

- 交易类型：短线试错、趋势波段、长线配置。
- 买入日期：用于判断持股是否还在最小观察期内。
- 单笔最大亏损：系统会结合成本价和止损价反推建议最大仓位。
- 账户资金：用于计算建议仓位占比、建议手数和当前计划亏损。
- 卖出闸门：收盘确认卖、先减半再确认、硬止损盘中可卖。
- 科技分歧规则：分歧期只做中军、龙头、分支核心，后排自动降级。

自选卡片会把计划翻译成可执行提醒，避免盘中急跌时一键情绪卖出。

自选卡片新增“交易计划状态”：

- 计划内：成本、止损、最大亏损和卖出闸门完整，按计划观察。
- 接近止损：价格、动态止损或卖点分级开始转弱，只降风险不补仓。
- 破计划：触发硬止损、清仓级卖点或动态风控危险，优先执行预案。
- 无计划：缺成本、股数、止损或最大亏损，禁止开仓/加仓。

今日行动清单新增“今日禁止操作”，集中提示禁止追买、禁止补仓、禁止低位情绪卖和禁止追回淘汰票。

交易计划检查同时承担仓位计算器作用：

- 按最大亏损和止损空间反推建议买入金额。
- 按实时价格换算建议手数。
- 已填持仓股数时显示当前仓位金额、账户占比和计划最大亏损。

自选卡片新增“计划止损”：

- 按成本价、现价、止损价、交易类型和承接状态动态生成保护线与硬止损。
- 亏损票优先守原始计划，盈利票自动从保本金切换为保护利润。
- 承接变差或触发硬止损时，会把动作标成反抽处理或执行预案。
- 动态止损会同步写入自选同步文本和自动复盘日志，方便盘后检查是否按计划执行。

顶部新增“持仓风险总览”：

- 汇总当前仓位、计划最大亏损、板块集中度和数据缺口。
- 缺少股数、成本或止损线时直接提示，不伪装成精确风控。
- 按动态止损硬线估算最坏情况，帮助小资金先守住本金。

### 5. 严格买卖点

当前买点包括：

- 放量突破
- 缩量回踩
- 弱转强
- 确认买点

卖点和风控包括：

- 到止损
- 跌破 20 日线
- 跌破 10 日线且不是缩量调整
- 放量分歧
- 到目标价后分批

如果数据质量不足，系统会阻断买点，提示先核验数据。

自选卡片新增“六灯纪律”：

- 趋势灯
- 量能灯
- 主线灯
- 环境灯
- 风控灯
- 形态灯

数据可信度是前置闸门，不计入六灯；数据不足时直接阻断确认买点。

环境灯现在同时看市场状态和个股相对强度：

- 大盘顺风，个股同步走强，环境正常通过。
- 大盘逆风，个股红盘且明显跑赢指数，标记为逆势强或逆势抗跌。
- 大盘逆风，个股只是跌得少，标记为相对抗跌，但仍需等待红盘和量能确认。
- 大盘逆风且个股没有相对强度，继续提示差环境。

逆势强只提高观察优先级；要变成确认买点，仍然需要趋势、量能、主线、风控和形态一起通过。

自选卡片新增“承接判断”：

- 观察低点收回、是否守住开盘附近、是否跑赢大盘、是否站住关键均线。
- 放量分歧、贴近低点和触发止损会降低承接等级。
- 输出别急着卖、等确认、反抽减仓或按计划止损，不把承接等同于买点。

自选卡片新增“卖点分级”：

- 清仓卖点：硬止损、计划止损、跌破关键趋势且放量走弱。
- 减仓卖点：到目标、放量分歧、接近保护线、承接转弱。
- 禁止卖点：还在计划内且承接未坏，避免盘中低位情绪清仓。

### 6. 中军 / 龙头自动切换

App 内置非创业板、非科创板的全市场主线核心池，并按主线强度和资金共振自动排序。

主线分为两层：

- 主攻科技：半导体、AI 算力、CPO、HBM、先进封装、电子特气等优先方向。
- 轮动观察：有色、小金属、稀土、煤炭能源、风电设备等非主攻方向。

轮动观察不会和主攻科技同权重抢位置，只有板块强度、资金共振和核心股趋势同时确认时，才会升级为轮动确认。

每条主线会标注：

- 中军：看板块持续性和大资金态度。
- 龙头：看板块弹性和短线强度。
- 分支核心：看细分方向是否扩散。

当其他板块成为领涨方向时，模块会自动把对应板块的中军和龙头排到前面。自选卡片中也会标注“中军”“龙头”“分支核心”“领涨主线”。

默认展示全部已配置主线核心池，避免先进封装、电子特气、光通信/海缆、风电设备、有色金属、小金属、稀土等重要分支被短期最强主线挤出视野。

中军/龙头卡片支持一键加入自选，会自动带入主线和观察理由；已在自选中的股票会显示“已在自选”。

主线强度会保存最近 5 日历史，用来观察当前领涨方向是延续还是切换。

### 7. K 线状态

使用日 K 数据判断：

- 是否站上 MA5 / MA10 / MA20
- 均线是否多头排列
- 距离 20 日高点的位置
- 当前是多头、修复、反抽还是弱势

如果缺少 K 线数据，系统不会给确认买点。

### 8. 资金异动雷达

雷达会扫描非创业板、非科创板、非北交所的主板大市值股票，默认过滤市值小于 300 亿的股票。

重点识别：

- 主力资金流入
- 大成交额异动
- 涨跌幅异常
- 板块归属
- 主线映射
- 个股定位和细分方向

雷达股票可以一键加入观察或设为持仓。

资金雷达新增“资金留痕”：

- 记录今日每次雷达快照。
- 标注首次上榜、连续上榜、回到雷达和上一轮掉出。
- 自选股从雷达掉出时会写入复盘日志，提醒不要把旧异动当成新买点。

### 9. 资金流向

市场环境下方会显示资金流向方向，直接展示：

- 流入方向
- 主力净流入
- 成交额
- 平均涨幅
- 主攻科技 / 轮动观察 / 轮动确认
- 代表异动个股

这个模块用于快速判断钱正在流向哪里，不替代买点确认。

资金流向下方带有时间轴：

- 9:35：开盘确认
- 10:30：上午持续
- 13:30：午后回流
- 14:30：尾盘确认
- 最新：最近一次雷达快照

时间轴会标注持续流入、方向切换、冲高回落、尾盘抢筹、资金分歧等状态，用来判断资金是否真的连续。

市场环境新增“宏观流动性灯”：

- 用上证、深成、创业板、科创50和两市成交额做公开行情代理。
- 结合资金雷达共振，输出进攻顺风、可试错、谨慎或收缩。
- 它只决定能不能进攻，不直接生成买点。

### 10. 主线聚合雷达

把资金异动股票按主线聚合，观察是否出现板块共振。

示例主线：

- AI 算力 / 服务器
- 光模块 / CPO
- HBM / 存储
- 半导体设备
- 半导体材料
- 先进封装
- 电子特气
- 面板 / 玻璃基板
- 光通信 / 海缆
- 风电设备
- 有色金属

### 13. 自选同步 / 复盘日志

支持：

- 复制自选同步文本
- 下载 JSON 备份
- 导入 JSON 备份
- 手动写入复盘

这个模块用于配合每天早上 8 点和晚上 8 点的简报/复盘，也用于长期统计自己最常犯的交易错误。

## 数据源与可靠性

当前使用免费行情数据源，可能出现：

- 请求失败
- 跨域失败
- 行情延迟
- 字段缺失
- 节假日或非交易时间数据不更新

因此 App 内置了数据可信判断：

- 行情是否加载
- K 线是否加载
- 行情时间是否过旧
- K 线日期是否过旧
- 实时价和 K 线收盘价是否异常偏离

只要数据可信不足，系统会提示“等数据”或“需核验”，不会把信号当成买点。

## GitHub Pages 部署

上传到 GitHub 后，可以用 GitHub Pages 直接部署静态页面。

推荐步骤：

1. 创建 GitHub 仓库。
2. 上传当前项目。
3. 打开仓库的 `Settings`。
4. 找到 `Pages`。
5. Source 选择 `Deploy from a branch`。
6. Branch 选择 `main`，目录选择 `/root`。
7. 页面地址通常是：

```text
https://<你的用户名>.github.io/<仓库名>/
```

根目录的 `index.html` 会自动跳转到 App 页面。
